# vue-frontend-demo

App Vue 3 + Vite de ejemplo para el curso Despliegue de Aplicaciones (ESAN).

- Semana 11: despliegue con Docker + Nginx y con Netlify, variables VITE_ y un secreto en una función.
- Semana 12: pipeline en `.github/workflows/ci-release.yml` (pruebas unitarias con Vitest, build, Release por tag y aviso a Slack).

Probar en tu PC:

    npm install
    npm run dev

Probar las pruebas unitarias:

    npm test
